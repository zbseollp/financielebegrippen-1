# Wat is een zakelijke bankrekening?

Dit is een bankrekening die bedoeld is voor een bedrijf zoals een eenmanszaak, Vennootschap onder Firma een B.V. of een N.V. ondernemingsvorm. Ook werken sommige zelfstandigen ofwel ZZPers met een [zakelijke rekening](https://www.nmanet.nl/zakelijke-bankrekeningen-vergelijken/). Het is dus een bankrekening vanwaaruit zakelijke betalingen B-to-B gedaan kunnen worden.
