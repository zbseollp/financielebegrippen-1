# Wat is Bic?

Bic staat voor Bank Idenifier Code ofwel de code van je bank. Elke bank heeft zo zijn eigen code, wat je kunt vergelijken met een adres. Hiermee kun je dus verifieren dat het om jou bank gaat. Een Bic heb je bijvoorbeeld nodig bij buitenlandse betalingen. Hieronder vind je de Bic codes voor de grootste Nederlandse banken.

## Bic ABN Amro

De bic = ABNANL2A

## Bic ING

De bic = INGBNL2A

## Bic Rabobank

De bic = RABONL2U

## Bic Knab

De bic = KNABNL2H
